## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Project setup

```bash
$ pnpm install
```

### Native binaries (local dev)

The `BoardModule` shells out to `yt-dlp` (and uses `ffmpeg` under the hood) to
resolve Instagram/TikTok URLs into raw video files before sending them to
Gemini. On macOS:

```bash
$ brew install yt-dlp ffmpeg
```

The production Docker image installs both via `apk add yt-dlp ffmpeg`.
Override the binary location with `YT_DLP_PATH` in `.env` if needed.

### Pin extraction (Gemini 2.5 Flash)

The `/board/pins/extract` flow downloads the source video via `yt-dlp`, then
uploads it to Gemini's Files API and calls
`streamGenerateContent?alt=sse` with `responseSchema` for clean structured
JSON. Pins stream back to the iOS client over SSE as they're parsed. The
uploaded file is deleted automatically once analysis completes (and
auto-expires after 48h regardless).

```env
GEMINI_API_KEY=...               # get one at https://aistudio.google.com/apikey
GEMINI_MODEL_ID=gemini-2.5-flash # default
GEMINI_BASE_URL=https://generativelanguage.googleapis.com
GEMINI_DEBUG=false               # set to "true" to log each SSE chunk + extracted text
```

**Cost (paid AI Studio tier):** `$0.30` per 1M input tokens (text/image/video)
and `$2.50` per 1M output tokens. A typical 60-second Reel is roughly $0.005
end-to-end. Context caching is available at `$0.03` per 1M cached input
tokens if we add request-level caching later.

**Free tier:** rate-limited (~10 RPM, ~1500 RPD on 2.5 Flash) — fine for dev,
not for production load. The per-user `@Throttle` of 20 extractions/day on
`POST /board/pins/extract` (`pin-extraction.controller.ts`) plus the AI
Studio tier are the only cost controls.

Without `GEMINI_API_KEY` set, the server still boots; the extraction
endpoint surfaces a clean `502` explaining what's missing.

## Compile and run the project

```bash
# development
$ pnpm run start

# watch mode
$ pnpm run start:dev

# production mode
$ pnpm run start:prod
```

## Run tests

```bash
# unit tests
$ pnpm run test

# e2e tests
$ pnpm run test:e2e

# test coverage
$ pnpm run test:cov
```

## Deployment

When you're ready to deploy your NestJS application to production, there are some key steps you can take to ensure it runs as efficiently as possible. Check out the [deployment documentation](https://docs.nestjs.com/deployment) for more information.

If you are looking for a cloud-based platform to deploy your NestJS application, check out [Mau](https://mau.nestjs.com), our official platform for deploying NestJS applications on AWS. Mau makes deployment straightforward and fast, requiring just a few simple steps:

```bash
$ pnpm install -g @nestjs/mau
$ mau deploy
```

With Mau, you can deploy your application in just a few clicks, allowing you to focus on building features rather than managing infrastructure.
